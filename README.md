# あさやけ図鑑 / Dawn Atlas

**朝起きられない × 空の収集。** 起きると決めた時刻から 15 分以内に空を撮ると、その朝の空の色が 1 マスになって、今月のパレットと図鑑に入る。寝坊した朝はマスが欠ける。起きる行動そのものが、集める遊びの入力になる（enludus-daily 2026-11-13、監督の題材 daily-ideas#23・予定 #19）。

- だれの：目覚ましを止めて二度寝する・朝のスマホで起きたことにしてしまう 20〜30 代
- どう使う：起きる時刻（曜日ごと）を決める → 朝、窓（15 分）の中で「空を撮る」→ 色が取れて、マスと図鑑のページが出る → パレットに置く
- 端末の中だけ：写真は色を読むためだけに使い、送信しない。写真を残さない設定もある。サーバー・ログイン・広告・解析なし。Apple Intelligence は使わない

| ホーム | 地平線と日の出の弧（右端の 15 分が窓、太陽が今の時刻の位置）・残り時間・「空を撮る」（太陽の形のシャッター）・続けた朝／いちばん長く／図鑑・今月のパレット（マス目）・1 年の輪・Pro の振り返り |

iPhone Duo の内側（size class が regular）では、左に窓と今月のパレット、右に図鑑と 1 年の輪を並べる（監督の注文 #23 の 6）。機種・向きでは決めない。

## 決まり（`App/Sources/Model/`、テストは `Tests/DawnSkyTests.swift`）

- 窓：起きる時刻〜15 分後は「窓の中」、2 時間前〜起きる時刻は「早起き」（印つき）、15 分〜6 時間後は「寝坊」（マスは欠ける）。それより前後は撮れない（`WakeWindow`）
- 最初の 1 枚は、窓の外でも「試し」として撮れる（最初の 10 秒で価値が分かるように。続けた朝には数えない）
- 1 日 1 枚。続けた朝は窓の中・早起きの日だけ数え、休む日（Pro）は飛ばす（`Journal.streak`）
- 色：写真の上 3/4 を空とみなし、24×32 に縮めて決まった初期値の k-means で 2〜3 色。写真の上にある色から並べる（`SkyExtractor`）
- 図鑑：色相・彩度・明度の割合、月日、起きた時刻、続けた日数で、上から順に当てはまる最初のページ（`SkyCatalog`）。日付のまぼろし（1 月 1 日・夏至・冬至）は窓の中だけ

## 世界観・トークン（2026-11-16 に作り直し）

- **世界は「夜明けの空そのもの」。** 画面の地は、時刻で変わる空のグラデーション（`Model/SkyClock.swift`：真夜中 → 夜明け前 → 青い時間 → 朝焼け → 日の出 → 朝 → 昼 → 夕焼け → 夕暮れ → 夜。決まった時刻の 3 色のあいだを混ぜる）。今日の空を撮った朝は、**撮った空の色そのもの**が全画面の地になる（白い文字が読める明るさまで沈める）。図鑑の 1 ページを開くと、そのページの空が地になる
- 白い枠のカードはやめた。文字と線は空の上に白で載せ、面は空に溶ける薄い白（ベール、不透明度 0.09）だけ。図鑑は**枠のない写真集の図版**（角 3pt の印画紙の形 `PlateShape`、下に「No.07」の番号と名前）
- 見出しと数字は**細いサンセリフ**（題は ultraLight、窓の残り時間は thin の 76pt。天気アプリの気温のように）。小さなラベルは大文字・字間 1.6
- 差し色は日の光：太陽 `#FFB37E`、空の上で読む金 `#FFD3A8`・`#FFE3BF`。主なボタンは空に浮く白い面（文字は夜の藍 `#141A3C`）
- 暗い地の形（`preferredColorScheme(.dark)`）にそろえ、トグル・時刻の選択・閉じるボタンも空の上で読めるようにした。起動画面も夜の藍
- 部品（`Views/Components.swift`）：空の色のマス `TileShape`・欠けたマス `ChippedTileShape`・地平線と日の出の弧の窓 `WindowDial`（太陽は光がにじむ）・365 本のくさびの `YearRing`・図版 `PageCard`
- アイコン：夜明けの地平線から半分のぼる太陽と、窓の弧（右の 15 分が桃色）
- 参考（借りたもの）：
  1. iOS の天気アプリ：時刻と空模様で全画面の地のグラデーションが変わる → ホームを含む全画面の地（`SkyBackdrop`）
  2. iOS の天気アプリ：ごく細い大きな数字と、大文字の小さなラベル → 窓の残り時間・続けた朝の数字・見出し
  3. 写真集（Apple の写真の「メモリー」の表紙）：枠のない図版と小さな番号・題 → 図鑑・発表のページ
- 前の見た目（〜11-15）との違い：地はほぼ白 `#F3F6F9` → 空のグラデーション（暗め・時刻で変わる）、色は淡い水色 1 系統 → 夜の藍から朝焼けの桃・金まで空の色、見出しは明朝（セリフ）→ 細いサンセリフ、主役の部品は白い枠のカード → 枠のない図版

## 手応えの表

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す | 0.94〜0.97 倍に沈む（spring 0.25） | `.selection` | なし |
| 1 つ成功（窓の中で撮った） | 色が写真から右へ 3 つ、55ms ずつ遅れて出る → マスが 0.6→1 倍 | `.success` | なし |
| 連続（続けた朝） | 数字が `numericText` で増える | （成功に含む） | なし |
| 失敗（寝坊） | マスの右上が欠けて薄く出る | `.impact(soft, 0.5)` | なし |
| 完了（新しいページ） | カードが -90°→0° にめくれ、1.03 倍に浮く（spring 0.42/0.72）・「新しいページ」の印 | `.impact(heavy)` | なし |
| 場面の切れ目 | 発表で撮った空が全画面の地に広がる（フェード 0.35s）・パレットに置く：画面を閉じて戻る。時刻が変わると地の空がうつる | `.impact(light)` | なし |

音は鳴らさない：朝は家族が寝ていることが多く、起きたての耳に効果音は強い（設定にも理由を書いた）。動きを減らす設定では、めくり・時間差・沈みを止めて最後の形を出す。

## 毎日開く理由

1. 今朝の窓（残り時間・お知らせ）と、その朝しか撮れない空の色
2. 今月のパレットが埋まっていく／欠けたマスが見える・1 年の輪
3. 図鑑 48 ページ（季節・日付・早起き・続けた日数でしか出ないページ）
4. 空のメモ 40 本・今月のパレットの共有カード

## デモで見せる流れ（起動引数 `-demo`、約 18 秒）

1. 見本の 40 日ぶんのパレットのホーム（窓が開いて、残り 7 分）
2. 「空を撮る」→ 朝焼けの空 → 色が 3 つに分かれ、図鑑の「地平の光」がめくれる
3. パレットに置く → 図鑑 → 今月の空のパレットの共有カード

## 課金

**形：買い切りの Pro ¥480（`com.enludus.daily.008.pro`、ファミリー共有あり）。** サブスクにしない理由：中身は図鑑のページ・書き出し・振り返りの解放で、毎月増える価値ではない（money.md §2）。

- 無料：空を撮る・窓と早起きと寝坊の判定・今月のパレット・1 年の輪（見るだけ）・図鑑 30 ページ・空のメモ・今月のパレットの共有
- Pro：めずらしい・まぼろしの 18 ページ（燃える空・星の残る空・地平の光・夏至や冬至・十四日目・三十日目・一時間早い朝など）、1 年の輪と朝の帯のポスター、30 日の平均・曜日ごとの割合、休む日
- 払う前に 1 回試せる：最初の 1 枚でめずらしい空が出ても、発表ではその色とページを見せる（図鑑に残すのが Pro）
- 出す場面：3 回目の朝を置いた直後に 1 回だけ（価値を感じた直後）。あとは鍵のページ・ポスター・振り返り・休む日を押したときだけ。起動時には出さない
- 値段は StoreKit の `displayPrice` を表示（コードに金額を書かない）

## 悩みの出典

監督の企画 #23（2026-11-13 13:37）と予定 #19。朝起きられない・二度寝は、20〜30 代の生の声が最も多い悩みの 1 つ（idea-fusion の例の方向）。先行事例：Pokémon Sleep（睡眠 × 収集、初年 約 $100M・売上の約 7 割が日本）。

## 作らなかったもの

- 目覚まし（AlarmKit）：目覚ましの作業ではなく「集めたくて起きる」形にするため。お知らせはローカルの補助だけ
- 写真の送信・クラウドの保存・友だちとの比較（サーバーなし）
- ウィジェット（次の候補：今朝の窓の残り時間と今月のパレット）
- Apple Intelligence（空の種類は色・日付・時刻のルールで決まり、AI がなくても成り立つ）

## 開発

```sh
brew install xcodegen && xcodegen generate && open DawnSky.xcodeproj
```

- 撮影：起動引数 `-screenshotScene <名前>`（`_ja` で日本語）。撮影とデモは見本のデータで動き、保存されたデータを書き換えない
- UI テスト：`UITests/MainFlowUITests.swift`（案内 → 起きる時刻 → 空を撮る（見本）→ 発表 → パレットに置く → 図鑑）
- 手元の確認：`scripts/scan-sensitive.sh .`、`python3 scripts/tone-check.py`
